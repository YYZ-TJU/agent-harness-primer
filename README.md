# Agent Harness Primer

**给数据科学背景的人的 Agent 入门读本**

> 你会用 pandas，懂模型训练和推理，但没写过生产系统。
> 这份读本假设你**不懂软件工程**，从"模型是个函数"讲起。

---

## 这份读本解决什么问题

你可能已经用过 ChatGPT，试过 LangChain 的 demo，但一到"做一个能用的 agent"就卡住：

- 模型为什么不肯调工具？
- 为什么聊久了就变傻？
- 它为什么一直重复查同一个东西？
- 怎么知道它到底对不对？

这些不是模型的问题，是**模型外面那一层**没搭好。

**那一层叫 harness。**

## 跑示例

```bash
git clone https://github.com/YYZ-TJU/agent-harness-primer.git
cd agent-harness-primer
pip install -r requirements.txt

python examples/ch1_langchain/e01_hello.py
```

**不需要 API key。** 示例用的是"假模型"，行为完全确定——你改一个参数，能确定变化是改动引起的，不是模型抽风。

## 几条写作约定

**一、不用黑话。**

原文里出现过"生成器""闭包""装饰器"这类词，全部换成了日常说法。

**二、事实与推断分开。**

标注「实测」的地方，是真跑过的数据。没标注的是设计意图或推断。

引用外部数据时标来源，见 [附录 B](appendix/B-数据来源.md)。

**三、能跑才算数。**

每个代码片段都可以单独跑。跑不起来的，会明确标注"这是伪代码"。

## 一个提醒

这份读本里有很多"我们踩过的坑"。

比如：

| 现象 | 原因 |
|---|---|
| 门禁从来没红过 | 那个检查项从未被触发 |
| 模型明明答对了却判失败 | 幂等表用了全局变量，跨用例污染 |
| 加了"优化"之后反而更差 | 那个优化有前提条件，我们不满足 |

**这些坑比"最佳实践"更值得看。** 因为最佳实践有前提，坑没有。
